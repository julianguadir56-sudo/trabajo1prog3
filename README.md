Integrantes: Julian Guadir, Alejandro ipaz.

## Contenido
- `actividad01.pl`: programa con los dos ejercicios
  1. Árbol genealógico de los Simpson (hechos: `padre/2`, `madre/2`; reglas: abuelos, tíos, primos, ancestros...).

## Cómo ejecutarlo
```
swipl actividad01.pl
?- abuelo(X, bart).
?- criminal(west).
```
